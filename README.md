## 🔹 Lab 05 - Ethernet LAN Switching

This lab demonstrates how switches dynamically learn MAC addresses and update their MAC address tables by examining ARP and ICMP traffic generated during communication between computers.

### ⚙️ Step-by-Step Configuration

#### Step 1 – Initial Setup

- Begin with empty MAC address tables on both switches (SW1 and SW2).
- Begin with empty ARP tables on all PCs (PC1, PC2, PC3, and PC4).
- [View Network Topology](Lab05-Ethernet-LAN-Switching/images/initial-topology.png)

#### Step 2 – Ping from PC1 to PC3

- ARP Request: PC1 broadcasts an ARP request asking "Who has 192.168.1.3?"
- All devices (PC2, PC3, PC4) receive this request.
- ARP Reply: PC3 responds with its MAC address directly to PC1.
- Once the ARP exchange is complete, ICMP Echo Request is sent from PC1 to PC3.
- PC3 responds with ICMP Echo Reply to PC1.
- [View Folder](Lab05-Ethernet-LAN-Switching/images/ping-from-PC1-to-PC3/)

#### Step 3 – Learning MAC Addresses

- The switches determine which MAC address is associated with each port by examining incoming Ethernet frames.
- Network traffic is generated by sending pings between PC2 and PC4, allowing the switches to learn MAC addresses.
- Once the destination MAC address is learned, subsequent unicast frames are forwarded through the appropriate port instead of being flooded.
- [View Folder](Lab05-Ethernet-LAN-Switching/images/ping-from-PC2-to-PC4-and-show-mac-address/)

#### Step 4 – Clear Dynamic MAC Addresses

- Use the `clear mac address-table dynamic` command to remove dynamically learned MAC addresses from the MAC address table.
- [View MAC Address Table Clearing](Lab05-Ethernet-LAN-Switching/images/clear-mac-address.png)

## 🔹 Lab 06 - Cisco Router IP Configuration

This lab demonstrates how to configure and verify router interfaces and host IP addresses to establish end-to-end connectivity across multiple networks.

### ⚙️ Step-by-Step Configuration

#### Step 1 – Check the Current Interface Status

- Use the `show ip interface brief` command to check the IP addresses and status of router interfaces.
- [View Interface Status](Lab06-Cisco-Router-Ip-Configuration/images/display-interface-status.png)

#### Step 2 – Configure the G0/0 Interface IP Address

- Enter interface configuration mode using `interface gigabitEthernet 0/0` and assign an IP address with a subnet mask using the `ip address` command.
- [View G0/0 IP Configuration](Lab06-Cisco-Router-Ip-Configuration/images/g0-0-ip-configuration.png)

#### Step 3 – Add an Interface Description

- Use the `description` command to document the interface connection.
- [View Interface Description Configuration](Lab06-Cisco-Router-Ip-Configuration/images/g0-0-description-configuration.png)

#### Step 4 – Activate the Interface

- By default, Cisco router interfaces are administratively shut down (disabled).
- Use the `no shutdown` command in interface configuration mode to activate the interface.  
- [View Interface Activation](Lab06-Cisco-Router-Ip-Configuration/images/g0-0-interface-activation.png)

#### Step 5 – Configure the G0/1 Interface

- Assign an IP address and subnet mask, add an interface description, and enable the G0/1 interface.
- [View G0/1 Interface Configuration](Lab06-Cisco-Router-Ip-Configuration/images/g0-1-all-ip-configuration.png)

#### Step 6 – Configure the G0/2 Interface

- Assign an IP address and subnet mask, add an interface description, and enable the G0/2 interface.
- [View G0/2 Interface Configuration](Lab06-Cisco-Router-Ip-Configuration/images/g0-2-all-ip-configuration.png)

#### Step 7 – Verify the Interface Configuration

- Use the `show ip interface brief` command to verify the configured interfaces.
- Check the assigned IP addresses and confirm that both `Status` and `Protocol` are **up**.
- [View Interface Status Verification](Lab06-Cisco-Router-Ip-Configuration/images/check-interface-status.png)
